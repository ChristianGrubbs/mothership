# Upload links (ask someone for files)

## Before you begin
An upload link lets someone outside The Mothership, such as a friend, a potential client or an employer, send you files without an account. They open the link, drop files and leave. What they send lands in a folder you choose, private and marked **To review**, until you accept it.

You need upload access to the folder the files should land in. The person you send the link to needs only a browser.

## Steps
1. Open **Upload requests** in the sidebar and select **New request**, or right-click a folder in the Library and choose **Request uploads…**. With **New request**, pick or create the destination folder and select **Select Here**.
2. In **Request uploads**, give the link a **Title** (what you are asking for, such as "Portfolio samples"). Optionally add **Instructions for guests**, which appear on the upload page.
3. Set the limits you want: **Link expires after** (7, 14, 30 or 90 days, or never), **Maximum files**, **Maximum size per file (MB)** and **Allowed file types** (for example `jpg, png, video/*`). Leave a limit empty for no limit beyond the Library's own.
4. Optionally tick **Require a password** and set one. Share it with the guest separately from the link.
5. Select **Create link**. In **Upload request ready**, select **Copy link** and send it by email, chat or text.
6. The guest opens the link, optionally adds a name and email, and drops files or selects **Choose files**. Each file shows **Sent** when it has arrived, and **Files you sent in this visit** lists it as **Received**.
7. Open the request from **Upload requests**. Each guest visit is listed with its files marked **To review**. Select **Accept** to let a file into the Library in the request's folder, **Accept into folder…** to put the selected files somewhere else, or **Reject** to move a file to the trash. Use the checkboxes with **Accept selected** or **Reject selected** for several files at once.

## Expected result
An accepted file shows **Accepted** on the request page and appears as an ordinary asset in the destination folder, where everyone with access to that folder can see it. A rejected file goes to the trash. The guest never sees the folder or any other file in the Library, only the files they sent in their own visit.

## Troubleshooting
If the guest sees **This upload link is not available**, the link has expired, was closed, or its creator's account is disabled. An expired link can be extended: open the request, select **Edit** and choose a new expiry. A closed link cannot be reopened, so create a new request.

If a link went to the wrong person, select **Reissue link**. The old URL stops working at once and you get a new one to send. Select **Close** to stop accepting files without deleting what has already arrived.

If a guest's file is refused, check the request's limits: too many files, a file over the size limit, or a type outside **Allowed file types**. Change them with **Edit** and ask the guest to try again.

If a file stays at **Finishing…** on the guest's page, the server is still processing it. It appears on the request page when processing finishes.
