# Library navigation and search

## Before you begin
Open **DAM > Assets** in the sidebar. This is the Library. What you can browse depends on your role and folder grants; **All assets** means all assets available to your account, not every asset in the system.

An ancestor folder may be shown only so you can navigate to a directly granted child. In a navigation-only ancestor, its own files stay hidden and upload, rename, and delete controls are unavailable. Continue through it to the folder your administrator granted.

## Steps
1. In **DAM > Assets**, select a folder in the directory tree or the folder list. Use the breadcrumb to confirm the current folder. Leave **Show subfolder contents** off to see files assigned to that folder only; turn it on to include available files from its descendant folders.
2. To search across folders available to your account, select **All assets**, then enter a term in **Search uploads…**. To search only the current folder scope, stay in that folder and use the same search box. Search can match an asset's displayed name, file name, Campus value, tag, or stack name.
3. Narrow the results with the **All**, **Images**, **Videos**, **SVGs**, or **Audio** media filter. Use **Filter** for file name, extension, tag, date, or available property filters. **Stack** shows only stacks, either any stack or one grouping (product, campaign, use case or other), and **Stack name** matches part of a stack's name in any letter case. A stack's card shows its grouping and name, for example *Campaign · Fall 2026 enrollment*, plus how many files it holds when there is more than one. Clear the search or filters to return to the broader available result set.
4. Use **Sort by** in either grid or list view. **Recently added** is the default and shows the newest uploads first; the menu also orders by name, size, or modified date in either direction, and the choice you make is remembered on this browser. Sorting applies to all matching results. Page controls above and below the results share the same current page and page size. To see related files together, select **Group by stack**: stacks are shown under **Product**, **Campaign**, **Use case** and **Other**, then by stack name, with plain assets last under **Not stacked**, each heading showing how many results on the page it holds. Select it again to return to the plain sort order; the choice is remembered on this browser.
5. Select an asset card or row to open it. Accounts with edit permission open the editable asset details; view-only accounts open the preview. When available, use the explicit **Preview** or **Edit** action instead.

## Expected result
Selecting an accessible folder lists its available files, and searching **All assets** finds the same accessible file by its matching information. Assets assigned only to folders your account has not been granted remain absent from the asset list and its result total, including **All assets** search results.

## Move folders
Drag a folder by its folder icon in the sidebar onto another folder or the explicit **Root** destination. Hover over a folder to expand it; dragging near the sidebar edge scrolls the tree. Valid destinations are highlighted. You can also open the folder’s **⋯** menu and choose **Move to…** to select a destination with the keyboard or touch.

Your account needs permission to move folders and access to both locations. A folder cannot move into itself or one of its descendants, and protected root folders cannot be moved. Wait for the move to finish before making another change; a failed move restores the tree from the server.

## Troubleshooting
If no results appear, clear the search, choose **All** for the media type, clear **Filter** values, and check whether **Show subfolder contents** matches the scope you need. An empty navigation-only ancestor does not mean its granted child is empty; continue to that child folder.

If an expected folder or file is still missing, ask an administrator to verify your role and folder grant. A restricted folder may be completely absent, while an ancestor may remain visible only as a path to content you can access.
